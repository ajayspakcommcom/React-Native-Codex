# React Native Roadmap

## Beginner (0-3 months)

### Foundations
- JavaScript (ES6+), TypeScript basics
- React fundamentals: JSX, components, props, state
- React Native core: `View`, `Text`, `Image`, `ScrollView`, `FlatList`
- Styling: Flexbox, `StyleSheet`
- Platform basics: Android vs iOS differences
- CLI vs Expo (start with Expo)

### Navigation & Data
- React Navigation (stack, tabs)
- Fetch / Axios
- Basic forms & validation

### Tools
- Metro, Expo DevTools
- Debugging: console, React DevTools
- Git basics

## Mid-Level (3-8 months)

### State & Architecture
- Hooks in depth
- Context API
- Redux Toolkit / RTK Query
- Clean component structure

### Native Features
- Permissions
- Camera, Media, Location
- AsyncStorage / MMKV

### Performance
- Memoization (`memo`, `useCallback`, `useMemo`)
- `FlatList` optimization
- Avoid unnecessary re-renders

### UI/UX
- Animations: Animated API, Reanimated (basic)
- Responsive layouts
- Dark mode, theming

### Testing
- Jest
- React Native Testing Library
- Maestro

### Builds
- Android APK/AAB
- iOS IPA
- Environment configs

## Senior (8-15 months)

### Advanced Architecture
- Modular architecture
- Feature-based foldering
- Dependency injection patterns
- Monorepos (Nx/Turborepo)

### Performance (Deep)
- Reanimated 2+
- Gesture Handler
- Interaction Manager
- Memory & bridge optimization

### Native Integration
- Native Modules (Java/Kotlin, Obj-C/Swift)
- TurboModules & Fabric (new architecture)
- Background tasks, push notifications

### Networking & Offline
- Advanced caching
- Offline-first apps
- Sync strategies

### CI/CD
- Fastlane
- GitHub Actions
- CodePush / OTA updates

### Security
- Secure storage
- Certificate pinning
- App hardening basics

## Expert (15+ months)

### Internals
- React Native bridge internals
- JSI
- Fabric renderer
- Hermes engine tuning

### Scalability
- Large-scale app patterns
- Multi-team code ownership
- Design systems
- Micro-frontends (where applicable)

### Advanced Native
- Custom UI components in native
- Performance profiling (Flipper, Xcode Instruments, Android Profiler)

### Release & Ops
- Crash analytics (Sentry, Firebase)
- Feature flags
- A/B Testing
- App size optimization

### Leadership
- Tech decisions & RFCs
- Mentoring developers
- Code reviews at scale
- Cross-platform trade-offs (RN vs Flutter vs Native)

## Must-Have Side Skills (Not required)
- Deep TypeScript
- REST + GraphQL
- Backend basics (Node.js)
- Mobile UX principles
- App Store & Play Store policies

## Final Goal
Build production-grade, high-performance, scalable apps and confidently handle native + JS + architecture + releases.
