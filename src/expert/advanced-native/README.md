# Advanced Native

This section covers the Expert-level native topics:

- `custom-native-ui-components`
- `performance-profiling`

## What We Did In This Section

### Custom native UI components
- Added an enterprise-style custom native UI component example with:
- a typed JS contract
- a native-view wrapper with safe fallback handling
- Android native view implementation and package registration
- iOS native view implementation files
- a console screen that consumes the component as product code would
- a `PENDING.md` file for rollout and verification work that cannot be honestly completed from app-side code alone

### Performance profiling
- Added an enterprise profiling topic with:
- tool contracts for Flipper, Xcode Instruments, and Android Profiler
- a profiling workflow model for release-build investigation
- a console screen that maps the correct tool to the correct problem class
- a runbook file for native-performance investigation
- a `PENDING.md` file for local tool installation, release-symbol, and device-profile rollout work
