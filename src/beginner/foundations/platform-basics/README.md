# Platform Basics

Main topics:
- Android and iOS UI differences
- Platform-specific behavior
- Safe areas
- Status bar differences
- Keyboard behavior
- Platform-specific files when needed

What to understand:
- Some components or behaviors differ between Android and iOS.
- You should design screens that work well on both platforms.
- React Native provides tools such as `Platform` to handle differences when necessary.

Goal:
- Recognize cross-platform differences early and avoid assuming both platforms behave exactly the same.
