# Styling

Main topics:
- Flexbox direction and alignment
- Spacing with margin and padding
- Width, height, and percentage-based layouts
- Colors and backgrounds
- Borders and radius
- Typography styles
- `StyleSheet.create`

Important notes:
- React Native styling is JavaScript-based, not CSS files.
- Flexbox is the main layout system.
- `StyleSheet.create` helps organize styles clearly.

Goal:
- Build clean, readable, responsive layouts using React Native styles.
