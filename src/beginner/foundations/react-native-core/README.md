# React Native Core

Core components to learn:
- `View`: basic layout container
- `Text`: render text content
- `Image`: render local or remote images
- `ScrollView`: scrollable container for smaller lists
- `FlatList`: efficient rendering for long lists

Why this matters:
- These components form the base of most React Native screens.
- Understanding when to use `ScrollView` and when to use `FlatList` is important early.

Goal:
- Be comfortable building simple screens with the main React Native building blocks.
