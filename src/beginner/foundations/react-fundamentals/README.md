# React Fundamentals

Focus areas:
- JSX syntax
- Functional components
- Props
- State
- Rendering lists
- Conditional rendering
- Event handling
- Component composition

Core concepts:
- JSX lets you describe UI in a component-friendly syntax.
- Props pass data from parent to child.
- State stores local changing data inside a component.
- Components should stay small and reusable.

Goal:
- Understand how React builds UI before going deeper into React Native.
