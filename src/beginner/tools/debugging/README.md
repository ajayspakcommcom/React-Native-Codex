# Debugging

## Focus Areas
- `console.log`, `console.warn`, `console.error`
- Reading red screen and runtime errors
- React Native Dev Menu
- React DevTools / React Native DevTools
- Inspecting component tree, props, and state
- Debugging user interactions

## What Matters In This Project
- Debugging is how you understand why the app is failing or behaving incorrectly.
- For beginners, this starts with logs and visible runtime errors.
- Later, this expands into component inspection and performance debugging.
